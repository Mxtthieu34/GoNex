# 🟣 GoNex - Buscador Web Real & Gaming Launcher

GoNex es un motor de búsqueda web moderno y centro de entretenimiento desarrollado con React y funciones Serverless (Vercel) conectadas a Brave Search API.

## 🚀 Características principales
- 🔍 **Búsqueda Web Real:** Resultados en tiempo real sin exponer credenciales en el navegador.
- 🌐 **Detección de URLs Directas:** Reconoce dominios directos para abrirlos instantáneamente.
- 🎮 **Biblioteca de Juegos & Utilidades:** Acceso rápido a juegos web integrados.
- 🖥️ **Visor Interno:** Carga sitios en iframe con detección automática de bloqueos de seguridad.
- ⭐ **Favoritos e Historial:** Guardado en almacenamiento local (`localStorage`).
- 🎨 **Diseño Dark Gaming:** Optimizado para Chromebooks, tablets y escritorios.

## 🛠️ Tecnologías utilizadas
- **Frontend:** React + Vite
- **Backend Serverless:** Vercel Functions (`/api/search`)
- **API de Búsqueda:** Brave Search API
